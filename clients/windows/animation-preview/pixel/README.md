# 도트 애니메이션 프레임 시험

`index.html`을 브라우저에서 열어 대기, 깜빡임, 말하기를 확인한다. 크기 조절로 실제 데스크톱 표시 크기도 시험할 수 있다. 서버나 의존성은 필요 없다.

`idle.png`는 선택된 도트 콘셉트다. `blink.png`와 `talk.png`는 내장 이미지 생성 도구로 각각 원본에서 눈을 감거나 입을 열도록 수정한 이미지다. 프롬프트는 각각 “원본의 위치, 크기, 색상, 휠체어와 투명 배경을 유지하고 눈만 감기”, “동일하게 유지하고 입만 작게 열기”이다.

프레임별 생성 결과는 얼굴 밖에도 차이가 있다. 따라서 이 파일은 움직임과 가독성 확인용이며, 균일한 격자의 수작업 스프라이트나 표정 8종을 완성한 것은 아니다.

`moods/index.html`은 설계 초안의 표정 8종을 비교하는 시안이다. 기본 이미지를 참조하여 내장 이미지 생성 도구에 각 감정의 얼굴만 바꾸고 자세, 휠체어, 색과 투명 배경을 유지하도록 요청했다. 표정마다 독립적으로 생성해 프레임의 일관성과 최종 격자 정리가 필요하다.
