# Codex 그림 요청: 히마리 큰 동작 v1

소유자 결정(2026-10-31): 큰 동작은 Codex에게 자세 그림을 받아 하나씩 도트로 옮겨 구현한다. 고개 돌리기는 제외한다. 아래 "요청문"을 참고 이미지와 함께 그대로 Codex에 넘긴다.

- 참고 이미지: `moods/neutral.png` (1230×1278, 투명 배경)
- 받은 그림은 `requests/big-motions-v1/`에 아래 파일 이름으로 넣는다.

---

## 요청문

첨부한 그림은 휠체어에 앉은 캐릭터 "히마리"의 기본 자세입니다. 이 그림을 바탕으로 **같은 캐릭터가 같은 자리에서 몸 일부만 움직이는** 애니메이션용 그림을 그려 주세요.

### 꼭 지켜 주세요

이 그림들은 원본과 겹쳐서 바뀐 부분만 잘라 쓰기 때문에, 바뀌지 않는 부분이 원본과 최대한 같아야 합니다.

1. **크기와 위치**: 1230×1278 투명 배경 PNG. 캐릭터와 휠체어의 위치, 크기, 카메라 각도를 원본과 똑같이 둡니다. 확대, 이동, 회전, 다시 구도 잡기는 하지 않습니다.
2. **화풍**: 원본과 같은 도트 그림 화풍입니다. 도트 한 칸은 원본과 같은 크기(약 6px)이고, 원본에 있는 색만 씁니다. 안티에일리어싱이나 흐림은 넣지 않습니다.
3. **바꾸지 않는 것**: 헤일로, 머리카락 모양, 얼굴 생김새, 리본, 교복, 겉옷, 휠체어, 신발. 동작 설명에 적힌 부분 말고는 원본 그대로 둡니다.
4. **표정**: 각 동작에 적힌 표정만 바꿉니다. 적혀 있지 않으면 원본 표정 그대로입니다.
5. **한 장에 한 장면**: 장면마다 PNG 한 장씩, 아래 파일 이름으로 주세요.
6. **중간 장면**: 적힌 중간 장면도 그려 주세요. 움직임이 자연스럽게 이어지도록 앞뒤 장면의 중간 위치여야 합니다.

### 지금 자세 (참고)

- 그림 오른쪽 손(캐릭터의 왼손)은 턱과 볼에 대고 있고, 팔꿈치는 굽혀 있습니다.
- 그림 왼쪽 팔(캐릭터의 오른팔)은 휠체어 팔걸이 위에 얹혀 있고, 손은 무릎 쪽에 놓여 있습니다.
- 무릎은 모으고, 두 다리를 그림 오른쪽 아래로 비스듬히 뻗고 있습니다.

### 동작 1: 손으로 입을 가리고 하품 (yawn-hand)

볼에 댄 손을 입 앞으로 옮겨 입을 가리고 하품한 뒤, 손을 원래 자리로 돌립니다. 다른 팔과 다리는 움직이지 않습니다.

| 파일 | 장면 |
|---|---|
| `yawn-hand-1.png` | 볼에서 손이 떨어져 입 쪽으로 반쯤 옮겨 감. 눈은 반쯤 감음 |
| `yawn-hand-2.png` | 손등(또는 손바닥)으로 입을 가림. 눈을 꼭 감고, 고개를 아주 살짝 뒤로 젖힘. 손가락 사이로 벌린 입이 조금 보여도 좋음 |
| `yawn-hand-3.png` | 하품이 끝나 손이 입에서 떨어져 볼 쪽으로 반쯤 돌아감. 눈은 반쯤 감음, 눈가에 작은 눈물방울 하나 |

### 동작 2: 기지개 (stretch)

무릎 위에 있던 팔(그림 왼쪽, 캐릭터의 오른팔)을 머리 위로 쭉 뻗고, 볼에 대고 있던 손(캐릭터의 왼손)으로 뻗은 팔의 팔뚝 중간(팔꿈치와 손목 사이)을 잡아 당겨 늘입니다. 다 늘인 뒤 두 팔이 원래 자리로 돌아옵니다. 다리는 움직이지 않습니다.

| 파일 | 장면 |
|---|---|
| `stretch-1.png` | 오른팔이 어깨 높이까지 올라옴. 왼손은 볼에서 떨어지기 시작함 |
| `stretch-2.png` | 오른팔이 머리 위로 거의 다 올라감. 왼손이 오른팔 팔뚝 쪽으로 올라감 |
| `stretch-3.png` | 오른팔을 머리 위로 쭉 뻗고, 왼손이 오른팔 팔뚝 중간을 잡아 당김. 상체가 살짝 늘어나고, 눈을 꼭 감은 시원한 표정 |
| `stretch-4.png` | 두 팔을 내리는 중. 오른팔은 어깨 높이, 왼손은 볼 쪽으로 돌아가는 중. 눈은 반쯤 감음 |

### 동작 3: 다리 바꿔 꼬기 (legs)

지금 다리 자세에서 다리를 잠깐 풀었다가, 반대쪽 다리가 위로 오도록 바꿔 꼽니다. 상체, 팔, 얼굴은 움직이지 않습니다. 휠체어 발판 위에서 움직이는 범위 안에서 그려 주세요.

| 파일 | 장면 |
|---|---|
| `legs-1.png` | 위에 있던 다리를 살짝 들어 풀기 시작함 |
| `legs-2.png` | 두 다리를 나란히 내려놓음(꼬지 않은 상태) |
| `legs-3.png` | 반대쪽 다리를 들어 꼬기 시작함 |
| `legs-4.png` | 반대쪽 다리가 위로 오게 다 꼰 자세(새 기본 다리 자세) |

### 덧붙여

- 원본과 다른 부분이 생기면(예: 헤일로 모양이 바뀜), 다시 그리지 말고 어떤 부분이 다른지 알려 주세요. 저희가 잘라 쓸 때 참고합니다.
- 장면 수를 줄여야 한다면 각 동작에서 가장 큰 장면(`yawn-hand-2`, `stretch-3`, `legs-4`)을 먼저 주세요.
