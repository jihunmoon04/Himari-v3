# 히마리 애니메이션 초기 시안

`index.html`을 브라우저에서 열면 서버나 설치 없이 미리 볼 수 있다. 앱 상태와 표정 이벤트를 선택하거나 가짜 대화를 재생할 수 있다.

이 시안은 생성된 한 장의 이미지를 움직이는 실험이다. 표정 8종은 이벤트 이름만 표시하며 별도 표정 그림, 눈 깜빡임, 입 모양, 파츠 리깅은 아직 없다. 윈도우 앱이나 서버 연결 구현이 아니다.

`himari-concept.png`는 내장 이미지 생성 도구로 만든 임시 콘셉트다. 프롬프트: “Blue Archive의 히마리, 은백색 긴 머리와 헤일로, 휠체어에 앉은 전신, 2.5등신 치비 애니메이션 스타일, 자신감 있는 미소, 투명 배경.” 원작과의 일치 여부를 검토한 뒤 후속 원화를 제작한다.
