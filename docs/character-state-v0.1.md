# 상태와 몸: 이어지는 기분·하루 리듬·앱에서 페르소나 바꾸기 v0.1 (캐릭터 로드맵 4단계, 2026-11-25)

[캐릭터 로드맵](character-architecture.md) 4단계. [삶](character-life-v0.1.md)·[관계](character-bond-v0.1.md) 위에 만든다. 소유자 방침(2026-11-25)에 따라 짧게 정하고 써 보며 고친다.

## 1. 무엇을 만드나

- **이어지는 기분:** 한 답의 표정이 아니라 몇 시간 이어지는 HIMARI의 기분.
- **하루 리듬:** HIMARI가 지금 무엇을 하고 있는지(자는 중, 일정 중 하나).
- **앱에서 페르소나 바꾸기:** 캐릭터 우클릭 메뉴 → 페르소나([companion-persona §10](companion-persona-v0.1.md#10-뒤-단계)).
- **그림이 필요한 것은 미룬다:** 이벤트 그림·애니메이션, 페르소나별 그림 세트는 그림이 생기면 한다.

## 2. 이어지는 기분

- **저장:** 주인 × 페르소나마다 지금 기분 하나. 표정 목록(`MOODS`)의 이름, 정한 시각, 출처(`reply`·`writer`), 까닭 한 줄(작가만).
- **정하는 곳:**
  - 답: HIMARI 최종 답의 **마지막 표정**이 `neutral`이 아니면 그것이 지금 기분이 된다. `neutral`만 있는 답은 기분을 바꾸지 않는다.
  - 작가: 일기와 함께 그날 끝의 기분과 까닭을 낼 수 있다(선택).
- **흐려짐:** 정한 지 **6시간**이 지나면 보이지 않는다(평소로 돌아감). 저장은 남긴다.
- **프롬프트:** runtime state `himari_mood`(6시간 안일 때만): 이름, 몇 시간 전, 까닭. 반려 절 `MOOD_RULE`(요지): 요즘 기분이 말투에 배게 하되 먼저 알리지 않는다. 사용자의 일이 먼저다. 시간이 지나며 자연스럽게 풀린다.
- **앱:** 기기가 연결되면 서버가 지금 기분을 표정 사건으로 한 번 보낸다(캐릭터가 그 표정으로 시작). 새 사건 없이 지금의 표정 사건을 쓴다.

## 3. 하루 리듬

- **자는 시간 = 먼저 말 걸기의 조용한 시간**(`HIMARI_PROACTIVE_QUIET`, 기본 23:00~08:00). 새 설정을 두지 않는다.
- **일정의 시각:** 작가가 일정에 시각(`HH:MM`, 선택)을 붙일 수 있다. 지금 시각에서 90분 안에 시작한 오늘 일정이 "지금 하는 일"이다.
- **프롬프트:** runtime state `himari_now`: `asleep`(조용한 시간), 지금 하는 일정 한 줄, 또는 없음. 반려 절 `LIFE_RULE`에 한 구절: 자는 시간에 사용자가 말을 걸면 깬 듯 짧게 답해도 된다. 지금 하는 일은 물으면 말한다.
- 먼저 말 걸기는 지금처럼 조용한 시간에 열지 않는다(바뀌지 않음).

## 4. 앱에서 페르소나 바꾸기

- **서버:** 기기 토큰의 좁은 예외 둘(H-45를 바꿈).
  - `GET /api/device/personas`: 번호와 이름, 지금 고른 것. 글은 주지 않는다.
  - `PUT /api/device/persona-choice`: 고르기(없음 포함), 리비전.
  - 바뀌면 사건 흐름에 `persona` 사건(번호, 이름). 다른 기기와 Web이 따라간다.
- **앱:** 캐릭터 우클릭 메뉴에 "페르소나" 하위 메뉴(목록 + 없음, 지금 것에 표시). 고르면 PUT, 실패하면 말풍선으로 짧게 알린다. `persona` 사건을 받으면 메뉴를 다시 읽는다.
- 글을 고치는 것은 지금처럼 Web에서만 한다.

## 5. 하지 않는 것(v0.1)

- 이벤트 그림·애니메이션, 페르소나별 그림 세트(그림 제작이 먼저).
- 기분에 따라 먼저 말 걸기 빈도를 바꾸지 않는다.
- 사용자의 기분을 따로 저장하지 않는다(일화가 이미 담는다).

## 6. 정한 것(권고안대로, 써 보며 바꿈)
